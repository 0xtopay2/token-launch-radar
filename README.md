This project provides a token launch radar that ranks pre-token protocols based on a custom scoring model. It identifies promising launches and generates detailed farm plans for each entry.

## Run it
`mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json`
